내 차 소모품 점검 및 정비 예산 플래너

차량을 운전하는 사용자가 주행거리에 맞춰 소모품 교체 시기를 확인하고, 본인의 예산과 정비 방식에 맞춰 실제 정비 계획을 세울 수 있도록 돕는 웹 서비스입니다.


1. 새로 추가한 기능
7주차에는 소모품 종류와 주행거리를 입력해 교체 필요 여부만 확인했다면, 이번 중간 프로토타입에서는 점검 결과 뒤에 이어지는 정비 방식(정비소 방문 / 셀프 DIY) 선택 및 가용 예산 시뮬레이션 기능을 새로 추가했습니다. 사용자가 선택한 정비 방식과 예산을 바탕으로 실행 가능 여부를 계산하고 그에 맞는 정비 체크리스트를 화면에 보여줍니다.


2. 새 기능의 동작과 상태 처리

[사용자 행동]
1단계에서 소모품 점검 결과를 확인한 뒤 '다음: 정비 방식 및 예산 시뮬레이션하기' 버튼을 눌러 2단계 화면을 엽니다. 이후 원하는 정비 방식을 고르고 가용 예산을 입력한 뒤 '예산 조건 확인 및 계획 생성' 또는 '예산 계산 취소하기' 버튼을 클릭합니다.

[확인하는 조건]
- 가용 예산 입력칸이 비어 있지 않은지 확인합니다.
- 입력한 금액이 허용 범위(10,000원 ~ 500,000원) 안의 숫자인지 확인합니다.
- 입력한 예산이 총 예상 정비 비용(기본 부품비 + 선택한 정비 방식의 추가 비용) 이상인지 비교합니다.

[조건별 화면 반응]
- 정상 성공: 예산이 충분하면 총 예상 비용과 남는 예산을 안내하고, 선택한 소모품과 정비 방식에 맞는 3단계 실행 체크리스트를 화면에 표시합니다.
- 입력 오류: 예산 칸을 비워두거나 10,000원 미만, 500,000원 초과로 입력하면 구체적인 수정 범위(10,000 ~ 500,000 사이 숫자 입력)를 안내하는 문구를 띄우고 입력창으로 포커스를 이동합니다.
- 결과 없음 (예산 부족): 입력한 예산이 총 예상 비용보다 적으면 실행 가능한 계획이 없다는 안내와 함께 부족한 금액을 알려주고, 예산을 늘리거나 비용이 적게 드는 셀프 정비(DIY)로 바꾸는 대안을 안내합니다.
- 취소 상태: '예산 계산 취소하기'를 누르면 예산 시뮬레이션이 취소되었다는 안내 문구를 보여주고, 1단계 점검 결과만 유지한 채 다음 행동을 선택할 수 있게 합니다.

[다음 행동 연결]
- '예산·방식 다시 수정'이나 '1단계로 돌아가기'를 누르면 이전에 입력했던 값들이 지워지지 않고 그대로 유지되어 바로 값을 고칠 수 있습니다.
- '처음부터 다시 시작'을 누르면 1단계와 2단계의 모든 입력값과 결과 화면이 초기 상태로 리셋됩니다.


3. 직접 테스트한 기록

- 정상 경로 테스트
1단계에서 엔진오일 세트와 주행거리 12000을 입력해 결과를 확인한 뒤 2단계로 이동했습니다. 정비소 방문 교체를 고르고 예산에 100000을 입력해 확인 버튼을 누르니, 총 비용 85,000원과 남은 예산 15,000원이 계산되어 나오고 정비소 방문용 체크리스트 3가지가 정상적으로 출력되었습니다.

- 입력 오류 테스트
2단계 예산 입력칸을 비운 채로 버튼을 눌렀을 때와 5000을 입력했을 때 모두 결과 화면이 열리지 않고, 10,000 이상 500,000 이하의 숫자를 입력한 뒤 다시 눌러달라는 빨간색 안내 문구가 정상적으로 표시되었습니다.

- 결과 없음(조건 미달) 테스트
엔진오일 세트와 정비소 방문 교체(총 비용 85,000원) 상태에서 예산을 50000으로 입력해 보았습니다. 체크리스트가 뜨는 대신 예산이 35,000원 부족하다는 안내 문구와 함께 셀프 정비 변경 또는 예산 수정을 권하는 안내가 나오는 것을 확인했습니다.

- 취소 및 값 유지·초기화 테스트
'예산 계산 취소하기' 버튼을 눌렀을 때 취소 안내가 잘 표시되었고, 이어서 '예산·방식 다시 수정' 버튼을 눌렀을 때 앞서 입력해 둔 예산 숫자(50000)가 지워지지 않고 그대로 남아 있어 바로 값을 수정할 수 있었습니다. 마지막으로 '처음부터 다시 시작'을 눌렀을 때는 모든 입력칸과 화면 상태가 처음 상태로 깨끗하게 초기화되었습니다.

- 데스크톱 및 모바일 화면 확인
PC 화면과 브라우저 폭을 줄인 모바일 화면에서 각각 조작해 보았으며, 화면이 좁아져도 입력창과 버튼이 화면 밖으로 밀리거나 서로 겹치지 않고 세로로 정렬되어 정상적으로 눌리는 것을 확인했습니다.
