# 내 차 소모품 점검 및 정비 예산 플래너 (중간 프로토타입)

## 1. 서비스 개요 및 새로 추가한 기능 설명
- **주요 사용자 및 목적**: 차량을 관리하는 운전자가 소모품 교체 주기를 점검하고, 본인의 예산과 정비 방식에 맞는 실행 계획을 세우기 위한 웹 서비스입니다.
- **7주차 대비 새로 추가한 기능**: 7주차 기본 흐름(1단계: 소모품 종류와 주행거리를 입력해 교체 필요 여부를 확인하는 기능)의 끝단에 이어, **선택한 소모품의 정비 방식(정비소 방문 vs 셀프 DIY)과 가용 예산을 입력받아 비용 충족 여부를 계산하고 맞춤형 정비 체크리스트를 생성하는 2단계 예산 시뮬레이션 기능**을 새로 추가했습니다.

## 2. 새 기능(2단계)의 행동·조건·상태 분기 및 다음 행동
- **사용자 행동**: 1단계 점검 결과 확인 후 `다음: 정비 방식 및 예산 시뮬레이션하기`를 눌러 2단계로 이동한 뒤, 정비 방식을 고르고 가용 예산을 입력하여 `예산 조건 확인 및 계획 생성` 또는 `예산 계산 취소하기` 버튼을 클릭합니다.
- **확인할 조건**:
  1. 가용 예산 입력값이 비어 있지 않은지 확인합니다.
  2. 입력한 예산이 허용 범위(10,000원 ~ 500,000원) 내의 숫자인지 확인합니다.
  3. 입력한 예산이 총 예상 정비 비용(1단계 소모품 기본 부품비 + 정비 방식별 추가 비용) 이상인지 비교합니다.
- **분기별 화면 반응**:
  - **성공 반응 (예산 충족)**: 총 예상 비용과 남은 예산을 계산해 보여주고, 선택한 소모품과 정비 방식(정비소/DIY)에 맞는 3단계 실행 체크리스트를 화면에 출력합니다.
  - **입력 오류 반응**: 예산 칸이 비었거나 10,000 ~ 500,000 범위를 벗어난 경우, "10,000 이상 500,000 이하의 숫자를 입력한 뒤 다시 버튼을 눌러주세요"라는 구체적인 수정 안내 문구를 표시하고 입력창으로 포커스를 이동합니다.
  - **결과 없음 반응 (예산 부족)**: 입력한 예산이 총 예상 비용보다 적을 경우, 부족한 금액을 구체적으로 안내하고 예산을 높이거나 셀프 정비(DIY) 방식으로 변경하라는 대안을 제시합니다.
  - **취소 반응**: `예산 계산 취소하기` 버튼 클릭 시 추가 시뮬레이션이 취소되었음을 안내하고 수정 또는 초기화 버튼을 제공합니다.
- **다음 행동 (값 유지 및 초기화)**:
  - `예산·방식 다시 수정 (입력값 유지)` 및 `1단계로 돌아가기 (기존 값 유지)`: 이전에 선택하거나 입력한 값을 지우지 않고 그대로 유지하여 바로 수정할 수 있게 합니다.
  - `처음부터 다시 시작 (전체 초기화)`: 1단계와 2단계의 모든 입력값과 결과 화면 상태를 초기화합니다.

## 3. 직접 시험한 테스트 기록
| 구분 | 입력 및 조작 방법 | 확인한 화면 반응 및 결과 |
| :--- | :--- | :--- |
| **정상 성공 경로** | 1단계에서 `엔진오일 세트`, `12000`km 입력 후 2단계로 이동 → `정비소 방문 교체`, 예산 `100000` 입력 후 확인 클릭 | 총 예상 비용(85,000원) 및 잔여 예산(15,000원) 안내와 함께 정비소 방문용 3단계 체크리스트가 정상 표시됨 |
| **입력 오류 경로** | 2단계 가용 예산 칸을 비우거나 `5000`을 입력하고 확인 클릭 | 결과 상자가 열리지 않고, 10,000 ~ 500,000 사이 숫자를 입력하라는 빨간색 오류 안내 문구가 정상 출력됨 |
| **결과 없음(조건 미달) 경로** | 1단계 `엔진오일 세트` 선택 후 2단계에서 `정비소 방문 교체`(총 85,000원 필요), 예산 `50000` 입력 후 확인 클릭 | 예산이 35,000원 부족하여 실행 계획이 없다는 경고 안내와 함께 셀프 정비 전환 또는 예산 수정 대안이 표시됨 |
| **취소 및 이전 단계(값 유지) 경로** | `예산 계산 취소하기` 클릭 후 `예산·방식 다시 수정 (입력값 유지)` 클릭 | 취소 안내 화면이 표시되었다가, 수정 버튼 클릭 시 기존에 입력했던 예산(`50000`)이 지워지지 않고 그대로 유지됨 |
| **전체 초기화 경로** | `처음부터 다시 시작 (전체 초기화)` 버튼 클릭 | 2단계 섹션이 닫히고 1단계 선택값과 입력창이 모두 빈 상태로 정상 초기화됨 |
| **반응형 화면 확인** | 데스크톱 브라우저 및 모바일 폭(375px)에서 화면 확인 | 모바일 폭에서 버튼이 세로 1열로 자동 정렬되며 화면 밖으로 밀리거나 겹치지 않음을 확인함 |
